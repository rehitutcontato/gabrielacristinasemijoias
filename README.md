# GC Semijoias & Acessórios — Catálogo Digital de Alta Conversão ✨

Catálogo digital mobile-first desenvolvido sob medida para **GC Semijoias & Acessórios** (Fundadora **Gabriela Cristina**). O projeto transforma a experiência de compra em uma jornada ágil e sem fricções, focada em tráfego do Instagram e fechamento direto de pedidos no WhatsApp.

---

## 💎 Funcionalidades

- **59 Produtos Reais Integrados**: Catálogo completo com brincos, colares, anéis, pulseiras, piercings e conjuntos.
- **Fotos em Alta Resolução**: Armazenadas localmente em `public/images/products/` para carregamento ultra-rápido (LCP < 1.0s).
- **Design System de Luxo**:
  - Paleta: `#FAF8F5` (Off-White Marfim) e `#C5A059` (Dourado Metálico Nobre).
  - Tipografia: *Playfair Display* e *Inter*.
  - Cards verticais 4:5 com acabamento arredondado de 16px (`rounded-xl`).
- **Filtros Inteligentes**:
  - Pílulas horizontais deslizantes por categoria com contadores dinâmicos.
  - Filtro por tipo de banho (*Ouro 18k*, *Ródio Branco*, *Banho Prata*).
  - Ordenação por preço e novidades.
  - Busca em tempo real no cabeçalho.
- **Modal de Detalhes da Peça (Quick View)**:
  - Visualização em alta definição com zoom.
  - Selos: 100% Hipoalergênico, Banho Nobre e 1 Ano de Garantia.
  - Seletor de quantidade e compra direta via WhatsApp.
- **Sacola de Compras Dinâmica (Cart Drawer)**:
  - Gaveta deslizante com revisão de itens e ajuste de quantidades.
  - Subtotal em tempo real e cálculo de parcelas em até 3x sem juros.
  - Persistência em `localStorage` por 30 dias.
- **Checkout WhatsApp Automatizado (Deep Linking)**:
  - Envio estruturado do pedido com itens, quantidades, valores e dados da cliente direto para o WhatsApp oficial: **+55 19 98331-7911**.
- **Botão Flutuante do WhatsApp**: Atendimento rápido com Gabriela Cristina a qualquer momento.
- **Mobile Bottom Navigation**: Barra fixa no rodapé para navegação nativa de aplicativo.

## 🚀 Como Executar Localmente

```bash
# 1. Instalar as dependências (se necessário)
npm install

# 2. Rodar o servidor de desenvolvimento
npm run dev

# 3. Gerar build de produção
npm run build
```

## 🌐 Publicação na Vercel

O projeto utiliza Vite + React e está 100% pronto para publicação estática com 1 clique na [Vercel](https://vercel.com):
1. Importe este repositório no painel da Vercel.
2. Mantenha o preset padrão (**Vite**).
3. Clique em **Deploy**.
